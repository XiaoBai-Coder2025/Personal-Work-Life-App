# 个人工作生活 App · 产品说明

日期：2026-09-22
状态：与演示原型（app-shell-structure-v7）一致
相关文档：[第一版设计](superpowers/specs/2026-09-21-personal-work-life-app-design.md)、[实现计划 1](superpowers/plans/2026-09-21-01-骨架与数据层.md)

## 1. 定位

一款只在本机运行的桌面端个人工作生活管理工具。它把"当天要做的事"和"长期推进的事"放进同一套数据：由智能排布生成草稿，经使用者确认后生效，数据全部保存在本机文件中。

| 项目 | 说明 |
| --- | --- |
| 运行环境 | 本机浏览器，桌面优先，启动即最大化 |
| 使用人数 | 单人 |
| 联网范围 | 仅地图工具与 AI 助手需要联网，其余功能离线可用 |
| 数据存放 | 项目目录下的文本文件，可备份、可迁移、可直接查看 |
| 账号体系 | 无登录、无云端、无部署 |

## 2. 功能总览

应用由七个模块组成，每个模块解决一类问题，不是同一个列表换名字。

### 2.1 首页总览

作用：一屏了解当天与近期状态，并随手记录。

内容：左列为"即将截止、今天的计划、长周期任务"，右列为"给你的建议、快速备忘、今天要去的地方"。

交互：每块都是可折叠抽屉，支持单独展开、单独收起，以及全部展开与全部收起。

边界：首页只做聚合与速记，深度编辑在各模块内完成。

### 2.2 今日计划

作用：按时间顺序呈现当天安排，并记录实际执行情况。

功能：到预定时间点时询问是否开始，提供"是""稍等一会""不做了"三个选项；"稍等一会"可自行填写推迟时长。确认后自动记录实际开始时间、结束时间与实际用时。支持手动添加、删除、顺延与勾选完成。

说明：顺延是按顺序与后一条任务交换先后并重新安排时间，而不是直接推移到次日；只有当天已无后续任务时才顺延到次日第一个空档。

### 2.3 日历日程

作用：呈现长期节奏与冲突。

功能：主体为任务轴线图（周一至周日 × 08:00-22:00），右侧配小月历用于跳转日期。任意一条日程都可修改开始与结束的日期和时间；跨天的条目会自动在任务追踪中形成一条进程条。存在时间重叠时，直接标注重叠时长。

### 2.4 任务追踪

作用：长周期任务的推进台账，回答"这件事还剩多少时间、会不会来不及"。

功能：

- 每条任务包含阶段（可增加、删除、切换）、进程条、交付日、风险与依赖说明
- 阶段与工作日绑定：每个阶段下列出它占用的具体时段（例如 20:00-22:00）
- 每天投入上限可设置；同一天分配给多个阶段时，各段时间之和不得超过当天上限，超出或不足都会明确提示
- 每天的安排以色条按阶段比例呈现
- 支持新建任务（可选阶段模板，自动把工作日铺开并分配到各阶段）、删除任务（先确认，并提示连带影响）
- 可让 AI 按任务的交付日、阶段与每天投入重新排一版安排

### 2.5 地图工具

作用：空间视角，解决"去哪、怎么去、几点出门"。

功能：地图铺满模块，左侧浮层为找地点、已标记、周边，右侧浮层为经过顺序与逐段行程。支持搜索并标记多个地点、逐段选择地铁/公交/骑行/驾车/步行、调整经过顺序并一键优化、按平日或节假日估算耗时。路径耗时会被智能排布用于计算出发时间。

### 2.6 AI 助手

作用：读取本机数据并回答与生成草稿的助手。

能力：读取今日计划、固定课表、日历日程、任务追踪与常用地址；能够按当前所在模块调整提问方式与快捷问题；能够把模糊目标拆解为逐日安排；能够从文件中提取日期并生成待确认草稿。

边界：所有产出先进入"待确认草稿"，经使用者采纳后才写入正式数据；不自动修改既有计划。

### 2.7 数据与设置

作用：身份、密钥、外观与数据管理。

内容：身份与作息、常用地址、固定课表与工作表、两把密钥（高德 JS Key 与 AI Key）、外观设置（亮/暗/跟随系统 × 五套配色，并支持跟随当地天气）、导出与导入备份、清空数据。

## 3. 主线与联动

智能排布 → 今日计划 → 日历日程 → 任务追踪，四个环节共用同一份数据；地图提供地点与路程时间，AI 助手读取以上数据并生成草稿。

典型联动：

- 在"今日计划"完成一段任务，"任务追踪"中对应时段自动标记完成，阶段进度同步更新；反向操作同样生效。
- 在"任务追踪"调整任务的周期，"日历日程"的轴线图同步更新。
- 地图估算的出发时间来自当日计划中的地点与到达时间要求。
- 首页的截止与长周期摘要均来自各模块的实时数据。

## 4. 产品特点

1. 以"阶段 × 每天时段"组织长期任务，而不是以任务清单堆叠。
2. 草稿制：智能排布、AI 与文件导入的结果都必须经确认才写入正式数据。
3. 数据自持：纯文本文件保存在本机，不依赖账号、云端与部署。
4. 模块各司其职：日历是时间轴，任务追踪是进程图，地图是空间视图，今日计划是当天时序。
5. 断网可用：除地图工具与 AI 助手外，其余功能在离线状态下正常工作。
6. AI 具备上下文且不越权：能读取本机数据、按当前页面调整交互，但不自动改动计划。
7. 桌面优先：窗口铺满屏幕、高度固定，模块切换不会引起版面跳动。

## 5. 期望的使用体验

**打开即可行动**：不需要先整理待办，首页已经给出当天的重点与临近的截止事项。

**长期任务不再依赖记忆**：剩余投入时间、可能的时间冲突、有风险的任务都摆在明面上。

**每件事只决策一次**：草稿就位，确认一次即可，后续环节自动衔接。

**数据掌控在自己手里**：不担心数据丢失，也不被任何平台绑定。

**工具保持安静**：需要时提供判断依据，不需要时不打扰。

## 6. 术语约定

| 术语 | 含义 |
| --- | --- |
| 模块 | 七个一级入口，如首页总览、任务追踪 |
| 任务 | 需要跨天推进、有交付日的一件事 |
| 阶段 | 任务内部的分段，可增加、删除、切换 |
| 时段 | 任务在某一天占用的具体时间，如 20:00-22:00 |
| 每天投入上限 | 一条任务每天最多安排的小时数 |
| 进程条 | 任务追踪中表示任务周期与完成比例的横条 |
| 交付日 | 任务的交付或截止日期，在进程图中以 ◆ 标记 |
| 草稿 | 由智能排布或 AI 生成、等待确认的安排 |
| 采纳 | 使用者确认草稿，将其写入正式数据 |
| 智能排布 | 依据身份、地点、固定课表与截止日期生成安排的核心能力 |

## 7. 范围边界

第一版不包含：账号与云同步、多人协作、手机端、部署上线、短信或邮件推送、自动抓取网站报名信息、离线地图瓦片下载、复杂统计报表。

完整的功能范围与技术方案以[第一版设计](superpowers/specs/2026-09-21-personal-work-life-app-design.md)为准。
